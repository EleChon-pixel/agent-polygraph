# agent-polygraph v0.2.1

Documentation-only patch on top of v0.2.0.

## Changes

- Replace the outdated prerelease notice in the README included with the npm package with version-neutral npm installation instructions.
- Preserve the existing agent-polygraph runtime and its privacy and security hardening.
- Keep npm package and Claude plugin version metadata aligned.

## Validation

The release CI suite checks six OS/Node combinations, packaging and installation, and a CLI demo. npm staging uses GitHub OIDC trusted publishing; public availability requires separate maintainer 2FA approval.

## Install

```sh
npx --yes agent-polygraph@0.2.1 --demo
```

The independent, blinded accuracy study remains open and is not claimed by this release.
