# agent-polygraph v0.2.0

The first security-hardened npm release of agent-polygraph, published through GitHub Actions trusted publishing with signed provenance.

## Highlights

- Guard and recorder settings changes use owner-only local backups and atomic updates, with symlink/hardlink checks.
- Improved path and snapshot handling on macOS and Windows.
- Version-aligned Claude Code plugin and npm CLI; safer shell recording installation.
- Release verification tests the actual packed package and CLI demo, plus Ubuntu/macOS/Windows CI.
- npm staging requires maintainer 2FA approval; no long-lived npm publish tokens.

## Installation

```sh
npx --yes agent-polygraph@0.2.0 --demo
```

## Scope and evaluation caveat

agent-polygraph checks *available evidence* supporting an agent's claim that tests passed; it does not itself run tests. The provided benchmarks are limited controlled scenarios, not independently validated accuracy. Independent blind evaluation remains open in [issue #3](https://github.com/EleChon-pixel/agent-polygraph/issues/3).
