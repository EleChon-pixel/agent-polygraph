# agent-polygraph v0.3.1 — README correction

**Published on npm.** This is a documentation-only patch for v0.3.0, approved with npm 2FA after [trusted-publisher staging](https://github.com/EleChon-pixel/agent-polygraph/actions/runs/41257569864). A [public-registry clean-install verification](https://github.com/EleChon-pixel/agent-polygraph/actions/runs/41257853213) confirmed v0.3.1, its corrected bundled README, working `explain` and `doctor` commands, and integrity metadata.

- Remove the obsolete statement that `explain` and `doctor` are upcoming features.
- Remove the obsolete claim that npm `latest` is v0.2.1.
- Explain how to check the public npm version dynamically instead of hard-coding it in evergreen README text.
- Add a regression test to prevent future README release-status drift.

No runtime behavior, CLI implementation, evidence-classification rules, privacy configuration or package dependencies were changed by this patch.
