# agent-polygraph v0.3.2 — claim evidence fixes

Published on npm and in [GitHub Releases](https://github.com/EleChon-pixel/agent-polygraph/releases/tag/v0.3.2). A clean public npm install was verified on 3 November 2026. The exact npm source commit is `c3cb6c329c5a2621319f74f9ecd2690bb864b33e`.

- Check every detected passing-test claim sentence in a message. A backed first sentence no longer hides a later failed claim. The guard quotes the actual flagged sentence.
- Abstain when a test ran in an unrelated checkout. Preserve subagent working directories in Claude Code and Codex, and avoid using another project's run for a generic claim in a multi-project session.
- Keep privacy-safe full/unknown scope in shell receipts. Targeted invocations and older category-only receipts cannot establish full-suite coverage; raw command arguments remain unsaved.
- Enumerate snapshot files from the Git root, including when the session starts in a package subdirectory.
- Isolate an installer test from host Bash startup banners.

Package and Claude plugin versions are both 0.3.2. No dependencies added. Reinstall shell integration with `agent-polygraph record --install --shell` after upgrading to regenerate its copied shell script; existing category-only receipts remain readable with unknown scope.

Validation and the utility assessment are documented in [usefulness-review.md](../usefulness-review.md).
