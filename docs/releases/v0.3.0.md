# agent-polygraph v0.3.0

**Published to npm.** `agent-polygraph@0.3.0` was staged with GitHub Actions OIDC trusted publishing and approved with maintainer 2FA. [Public npm verification](https://github.com/EleChon-pixel/agent-polygraph/actions/runs/41256795869) installed the immutable tarball and confirmed the CLI, demo, `doctor`, `explain`, SHA-512 integrity and bundled README.

## Accuracy and correctness

- Prevent GitHub workflows with skipped, neutral or inconclusive test jobs from backing passing-test claims. Inspect actual test-job and test-step conclusions instead of inferring execution from a workflow's name.
- Treat explicitly full-suite claims after only targeted test runs as **inconclusive**, not automatically backed. Prefer an observed full-suite run even when no reliable pass count was printed.
- Add regression cases for skipped tests, failed test steps, neutral CI outcomes and test-scope mismatches.

## Diagnostics

- `agent-polygraph explain`: read-only, local explanations of flagged and inconclusive claims with the last observed test evidence and subsequent edits. Supports session prefix, project/agent/date filtering and optional GitHub Actions enrichment.
- `agent-polygraph doctor`: read-only local diagnostics for transcript discovery, a small log-format sample, project/global hooks and recorder-directory permissions.
- Both commands are optional; existing `agent-polygraph`, `guard`, `record`, `--html` and `--json` workflows retain their existing behavior.

## Documentation

- Remove an obsolete prerelease notice and document the new commands' privacy boundaries.
- Document the distinction between the public npm package and development on GitHub `main`.

## Evaluation limitations

This release does **not** claim independent human-validated precision or recall. The [blinded accuracy study](https://github.com/EleChon-pixel/agent-polygraph/issues/3) still requires independently recruited reviewers and held-out first-pass labels. Incremental disk caching and new shell/CI integrations remain potential subsequent work; they were deliberately not added without their own privacy and compatibility validation.
